请基于当前目录，为一个跨境卖家税务 SaaS 管理系统进行全栈开发。该系统旨在提供一站式的多国税务申报、税金核算及数据查询功能。

### 1. 技术栈评估与决策请求

在开始编码前，请针对以下业务场景对比 **Node.js (TypeScript/NestJS)** 与 **Python (FastAPI/Django)** 的优劣，并给出最终建议：

- **数据与并发**：约 50,000 条记录，日活用户 (DAU) 约 300 人。
- **业务特性**：涉及复杂的多国税务逻辑核算（计算密集型 vs 逻辑密集型）、第三方申报平台 API 集成（异步处理需求）。
- **数据库推荐**：基于税务数据的高一致性要求，请在 PostgreSQL 和 MySQL 之间推荐方案，并说明理由（如对 JSONB 的支持以应对不同国家的申报字段差异）。

**前端要求**：使用 React + Vite + Ant Design + Tailwind CSS (可选)。必须实现响应式布局，适配 PC 桌面端和移动端。
